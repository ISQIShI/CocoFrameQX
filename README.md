# CocoFrameQX

## 通用模块

- [玩法配置系统](Config/README.md)：强类型参数、分层覆盖、运行时校验、实时/重启生效、Web 测试面板、JSON 导入导出与复现链接。包含独立接入示例，现有玩法按需迁移。
- [服务容器](Service/README.md)：类型化令牌、显式工厂、父子作用域、异步就绪与所有权释放。
- [事件系统](Event/README.md)：类型化事件、独立订阅句柄、订阅作用域及显式 Cocos 生命周期适配。

Event 与 Service 的新版 API 是破坏性升级；旧的事件参数重载、监听装饰器、链式绑定和自动生命周期探测已移除。各模块 README 提供迁移说明。核心入口不导入 `cc`，Cocos 适配器通过各自文件单独导入。业务入口负责创建、装配和释放服务，避免在业务对象内散布全局容器访问。
